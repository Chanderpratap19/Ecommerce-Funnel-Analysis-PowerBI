# E-commerce Funnel Analysis | Power BI

## 📌 Problem Statement
An e-commerce company had 10,000 website visitors but only 253 purchases. 
This is an 89.96% drop-off, resulting in an estimated 2.4M in revenue loss.

## 📊 Key Insights
1.  **Biggest Leak**: Checkout Stage - 3.5K users dropped
2.  **RCA**: Issue is consistent across Region, Channel, Device, and Time
3.  **Conclusion**: Points to a core UX/Checkout problem, not marketing
